欢迎来到我的技术博客！这里会持续分享我的技术学习笔记、踩坑记录与项目实践。

## 本站技术栈

本站由以下技术驱动：

- **Hexo**：快速、简洁且高效的静态博客框架
- **Butterfly 主题**：美观且功能丰富的现代博客主题
- **Cloudflare Pages**：免费托管，全球 CDN 加速
- **GitHub**：代码托管，推送即自动部署

## 如何写新文章

在项目根目录执行：

```bash
hexo new post "文章标题"
```

Hexo 会在 `source/_posts/` 下生成同名 Markdown 文件，编辑完成后推送到 GitHub，Cloudflare Pages 会自动构建并发布。

## Markdown 写作示例

支持常用的 Markdown 语法：

**粗体**、*斜体*、`行内代码`、[链接](https://hexo.io)

> 引用块：好的博客贵在坚持。

表格：

| 功能 | 说明 |
| ---- | ---- |
| 暗色模式 | 主题内置，跟随系统或手动切换 |
| 文章搜索 | 主题内置本地搜索 |
| 评论系统 | 可选接入 Valine / Waline / Giscus 等 |
